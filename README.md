# PLC Learning Portfolio — Ujwala Venuturla

## Week 1 — PLC Programming Foundations

### Programs Built
| Program | Language | Tool |
|---|---|---|
| Motor Start/Stop with Latch | Ladder Logic | TIA Portal V17 |
| Timers & Counters (TON/TOF/CTU) | Ladder Logic | TIA Portal V17 |
| Motor Control Function Block | LAD + SCL | TIA Portal V17 |
| SCL Motor Conveyor System | SCL | TIA Portal V17 |
| SFC Tank Filling Sequence | SFC | CODESYS |
| 2-Motor Conveyor Mini Project | LAD + SCL | TIA Portal V17 |

### Concepts Mastered
- IEC 61131-3 languages: LD, SCL, SFC, FBD
- Function Blocks (FB) with Data Block instances
- Sequential Function Charts with actions and transitions
- Timer and Counter blocks (TON, TOF, CTU)
- Motor interlock logic and latch circuits

### Tools Used
- Siemens TIA Portal V17
- CODESYS V3.5
- PLCSIM (simulation)
